# JS Quiz Arena

A simple quiz app built with HTML, CSS, and vanilla JavaScript for Week 1 Task 1.

## Features

- One question at a time with four clickable options
- Progress line and live score
- Green/red answer feedback, correct answer reveal, explanation, and locked options
- Next and Restart buttons
- 30-second countdown for each question
- Automatic answer reveal when time runs out
- Final score and rating message
- Review Wrong Answers screen at the end

## Files

- `index.html` — page structure
- `style.css` — styling
- `script.js` — questions and quiz logic

## Run locally

Open `index.html` in your browser. No installation is required.
